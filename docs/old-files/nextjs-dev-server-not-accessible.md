"---\ntitle: Next.js Dev Server läuft aber ist nicht erreichbar\ntags: [nextjs, troubleshooting, vs-code, port-forwarding]\n---\n# PROBLEM\nNach `npm run dev` zeigt der Terminal, dass der Next.js Dev Server läuft (z.B. auf Port 3000), aber die Seite lässt sich nicht aufrufen. Weder direkt auf localhost noch über VS Code Port Forwarding. Es sind keine Fehlermeldungen im Terminal sichtbar.\n\n# LÖSUNG\n1. Überprüfen, ob der Server tatsächlich auf dem Port hört (netstat/lsof)\n2. Standardmäßig hört Next.js nur auf localhost (127.0.0.1) - hostname muss angepasst werden\n3. VS Code "Ports"-Tab öffnen und richtigen Port suchen\n4. Browser-Cache leeren und incognito mode testen\n\n# CODE / COMMANDS\n\n## Schritt 1: Server-Prozess und Port prüfen\n```bash\n# Prüfen, ob Port 3000 belegt ist\nnetstat -tulpn | grep 3000\n\n# Oder mit lsof (auf macOS/Linux)\nlsof -i :3000\n\n# Prüfen, ob npm/next Prozess läuft\nps aux | grep node | grep next\n```\n\n## Schritt 2: package.json Start-Kommando anpassen\n**Problem:** Next.js Dev Server läuft standardmäßig nur auf localhost (127.0.0.1)\n\n**Lösung:** Starte mit `-H 0.0.0.0` um auf allen Interfaces zu hören\n\n```json\n// package.json\n{\n  \"scripts\": {\n    \"dev\": \"next dev -H 0.0.0.0 -p 3000\"\n  }\n}\n```\n\nAlternativ im Terminal direkt:\n```bash\nnpx next dev -H 0.0.0.0 -p 3000\n```\n\n## Schritt 3: VS Code Port Forwarding prüfen\n1. Gehen zum \"Shield\" (Remote Explorer) oder \"Ports\" unten\n2. Suchen nach Port 3000\n3. Klicken auf \"Forward Port\" wenn ihn nicht da ist\n4. Klicken auf \"Open Browser\" Icon\n\n## Schritt 4: Browser Debugging\n```javascript\n// In Browser Console (F12):\n// Prüfen, ob request überhaupt geht\nfetch('http://localhost:3000').then(r => r.text()).then(console.log)\n```\n\n# SHELL OUTPUT / ERROR\n\n**Working Terminal Output (Server läuft korrekt):**\n```\n$ npm run dev\n\n  ▲ Next.js 14.x.x\n  - Local:  http://localhost:3000\n  - Network: http://192.168.x.x:3000\n\n Ready in 2.3s\n```\n\n**Problem Signs:**\n```\n# Wenn nichts auf Port 3000 läuft:\nnetstat -tulpn | grep 3000\n# (no output)\n\n# Wenn nur auf localhost statt 0.0.0.0 hört:\nLocal:  http://localhost:3000\n# (fehlt Network row)\n```\n\n# WEITERE RESOURCEN\n- Next.js Dev Server Docs: https://nextjs.org/docs/app/api-reference/next-config-js/dev\n- VS Code Remote Port Forwarding: https://code.visualstudio.com/docs/remote/ssh#_managing-ports\n\n---"
